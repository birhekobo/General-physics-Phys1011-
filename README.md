# General Physics (Phys 1011)

Interactive course materials for the undergraduate General Physics course.

## Course website

Once GitHub Pages finishes deploying, the site will be available at:

https://birhekobo.github.io/General-physics-Phys1011-/

## Local preview

Open `index.html` in a browser. The site uses relative links and has no build step.

## Deployment

GitHub Actions deploys the static site to GitHub Pages whenever changes are pushed to `main`.
